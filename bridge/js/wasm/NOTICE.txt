compiled.js and compiled.wasm are a WebAssembly build of DDS, the Double Dummy Solver by Bo Haglund and Soren Hein
(https://github.com/dds-bridge/dds, Apache License 2.0, see LICENSE-dds.txt), built by build.sh from the same sources and C interface as
the npm package @bridge-tools/dd 0.2.2 (https://github.com/aaron-hutton/bridge-tools, MIT license, see
LICENSE-bridge-tools.txt): DDS 2.9.0 as adapted in https://github.com/aaron-hutton/dds (commit 860e618), and
dds_wrapper.cpp, based on that package's src/dds/dds_wrapper.c. The build here is optimised (-O3), and its
memory grows as needed.
Attribution is kept in bridge.html in a comment above the embedded copy.
